# 智谱云端演示部署

先注册并登录 https://dashboard.render.com/ ，可使用 GitHub 登录。选择免费演示服务前，核对平台当前套餐、账号验证及收费提示。

此版本支持页面与后端部署在同一 Render Web Service，新链接可直接分享给访客，GitHub Pages 原链接仍为独立静态演示，不会自动连接云端。

## 准备代码

GitHub 当前仅有单文件网页，需要将完整源代码上传到仓库后再部署。不要上传真实 .env 或密钥。源码目录的 dist、server、server.cjs、package.json 和 render.yaml 必须保留原目录结构。

## Render 配置

创建 Web Service，选择这个 GitHub 仓库；运行环境 Node；Build Command 为 `node --check server.cjs`，Start Command 为 `node server.cjs`，Health Check 为 `/api/health`。免费套餐只用于试用，15分钟无访问会休眠，唤醒较慢且内存会话会丢失。

Environment 中添加：
- NODE_VERSION = 22.16.0
- LLM_PROVIDER = zhipu
- ZHIPU_BASE_URL = https://open.bigmodel.cn/api/paas/v4
- ZHIPU_MODEL = 你的账号可用模型 ID（如 glm-4.7，需实际确认）
- ZHIPU_API_KEY = 仅在 Render 私密环境变量中填写
- DAILY_AI_LIMIT = 100

不要手填 PORT，Render 会自动提供。服务以 RENDER_EXTERNAL_URL 识别实际公网 Host 和 HTTPS 来源，只允许同站浏览器请求。自定义域名可用 PUBLIC_ORIGIN 指定无路径的 HTTPS 站点。

发布成功后，打开 Render 给出的实际网址，刷新连接并运行 AI 审查。用两份不同合同验证会话互相独立，再分享。当前未验证真实智谱 Key 或实际云端到智谱的网络可用性。

## 演示限额与会话

无需注册即可使用。每次审查分配不可预测的会话编号，持有该编号才能追问；不要把编号或含合同的导出报告公开。合同、对话只放服务内存，闲置30分钟失效，重启/休眠即丢失。

同时最多4个请求，全局每分钟60个POST；默认每日100次AI尝试（包含审查和追问，失败也可能计数），单进程内存计数，UTC换日或重启清零，不能作为持久费用硬上限。应同时在智谱控制台使用其提供的额度管理功能，正式运营需持久化配额及更完整的访客防滥用措施。

源站检查不能阻止所有直接调用，当前适合小范围公开试用。AI 条款及引用仍需法务复核，合同将发送给智谱服务。
