# 知界 v1.1：用户端与管理端分离

本次提供的是可部署的新代码，尚未替换你腾讯云上运行的旧版本。

## 两个入口

- 用户端：原腾讯云网址首页 `/`。只查看资讯、审查合同、查看只读审查依据。
- 管理端：在原网址末尾加 `/admin`。管理采集、每日时间、共享规则和备份。采集、设置和发布仍须输入原管理员口令。

管理员草稿与普通用户使用的已发布规则分开；用户页不再显示采集按钮、设置、错误日志、规则编辑或发布入口。管理员可点“返回用户端”。管理页面地址本身公开，关键写入操作由服务端验证管理员口令；本版没有独立账号登录系统。

## 一次更新

1. 下载并解压 `知界完整系统-v1.1.zip`。
2. 将里面 `zhijie-tencent-deploy` 文件夹的文件上传并覆盖 GitHub 仓库中同名文件夹内的旧文件。保留文件夹名称和目录结构，勿上传 ZIP 本身，也勿在旧文件夹内再嵌套一层。
3. 腾讯云更新服务，目标目录仍是 `zhijie-tencent-deploy`，Dockerfile 名称仍是 `Dockerfile`，服务端口仍为 `4173`。保留现有环境变量，无需重新填写密钥。
4. 更新成功后刷新首页，访问 `/admin`。在“自动采集设置”中关闭可选 AI 摘要、开启自动采集，保存。点击“立即采集”，输入原管理员口令。

基础采集现在直接读取官方网页、按主题筛选和去重、保存摘录与链接，不需要智谱密钥。已通过真实网络运行：三个官方栏目全部成功，保存 8 篇，模型调用 0 次。对应真实运行结果另附 JSON，未混入用户站点冒充线上采集结果。

自动任务在服务实例运行时，按北京时间每天指定小时执行；实例休眠不能保证准时唤醒。数据目录需要持久化挂载才能跨重新部署保留；设置 `DATA_PERSISTENT=true` 本身不会创建挂载。单次默认 8 篇、最多 30 篇，不代表覆盖全网；首次可能采集历史内容，发布日期和发现日期分别显示。PDF 附件全文暂不解析。

智谱 HTTP 401 仍须在腾讯云核对模型密钥；基础采集和规则审查可以独立使用。新版本可选 AI 摘要认证失败时保留原文结果，并停止本轮后续 AI 尝试，不会丢弃资讯。

## 一分钟以内录屏

- 0–10 秒：打开用户端法律情报中心，说明“我追踪知识产权法律政策、司法动态与相关新闻”。
- 10–25 秒：打开 `/admin`，展示“官方来源 → 主题筛选 → 去重 → 原文摘录 → 每日更新”，展示自动采集时间。提前完成一次真实采集，录屏时展示其完成记录，避免等待占用一分钟。
- 25–45 秒：返回用户端，展示实际资讯、发布日期、摘录和官方原文链接；打开一条原文核验。
- 45–55 秒：说明“它会持续收集和去重；无需模型也能运行，AI 摘要可选。输出可追溯资讯，辅助法律监测”。

不要把预存结果说成录屏时刚运行；展示记录对应真实运行时间即可。本文为录屏步骤，未附成品视频。

## 本地运行与验证

需要 Node.js 22.16 或更高版本。进入解压后的 `zhijie-tencent-deploy` 文件夹，运行 `npm start`，打开 `http://localhost:4173/` 和 `http://localhost:4173/admin`。本地管理操作先从 `.env.example` 复制 `.env`，设置自己的 `INTEL_ADMIN_TOKEN`（至少 16 位）。基础采集无须填写模型密钥。

`npm test`：40 项检查全部通过，包含用户端隐藏管理操作、服务端写入权限、管理员页面资源路径、规则发布冲突、无模型采集、可选 AI 认证失败后保留原文、合同审查与引用校验。未完成真实浏览器视觉验收。
