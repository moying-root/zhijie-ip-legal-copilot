# 知界 IP Legal Copilot 1.0

单实例 Node.js 完整系统，包含前端、后端、智谱接口、官方网页采集、每日调度、共享规则和测试。沿用清华紫色调及小树 Logo。无需安装第三方运行依赖，要求 Node.js 22.16+。

## 已实现

- 法律情报中心：站内立即采集、管理员验证、后台进度、任务历史、自动时间设置、分类/搜索、官方原文、AI摘要及业务提示、发现时间和发布日期区分、来源错误展示。
- 合同工作台：甲方/乙方/中立；FDE驻场开发、AI大模型、委托研发、技术许可；规则/AI审查、TXT导入、报告JSON导出、追问与改写、无需先审查的独立条款起草及TXT导出。
- 规则管理：新增/编辑/删除/启停、来源关联、JSON导入导出、本地未发布草稿、管理员发布共享版本、并发修改冲突提示。
- 系统状态：查看模型配置、每日调度、管理员配置及存储声明；管理员导出备份、恢复情报和规则。
- 真实情报为空时显示空状态，不提供虚构每日新增；法律依据示例仍作为已内置的审查参考，不能代替全面法律检索。

## 本地启动

1. 在本目录将 `.env.example` 复制为 `.env`。
2. 填写智谱 API 密钥、实际可用模型、随机管理员口令（建议24位以上）。本地 PUBLIC_ORIGIN 留空。
3. 运行 `node server.cjs`，浏览器打开 http://127.0.0.1:4173 。未配置模型仍可进行关键词规则审查；AI和采集摘要需要智谱。
4. `npm test` 运行全部自动化测试；`npm run check:sources` 只检查官方来源，不调用模型。

可选本地Docker：准备 `.env` 后执行 `docker compose up --build -d`。本地具名卷保存数据。此路径未在当前环境实际构建验证。

请查看完整包根目录的《部署与使用说明.md》。上传目录固定为 `zhijie-tencent-deploy`，目标目录也填写此名称。不要把ZIP压缩包直接上传作为代码。使用腾讯云网站地址，GitHub Pages 原静态页不会自动变成后端系统。

## 数据和运行条件

- 合同与对话不写入数据目录，审查会话闲置30分钟或重启后失效；模型服务商如何处理请求由其政策决定。
- 共享规则、情报、任务记录、调度设置和合同AI额度计数写入 `INTEL_DATA_DIR`，默认项目 `data/`，容器 `/app/data`。重建容器保留历史必须挂载持久化存储。
- 后端内置计时器仅在进程运行时检查每日任务；无法唤醒缩容到0的云实例。每天到点后首次运行时会补执行当天尚未开始的定时任务。
- 只支持单实例，请将腾讯云最大实例数设为1；需要内置每日任务可靠执行时还需最小实例数1，这可能增加费用。没有持久化与常驻实例不能宣称每日可靠运行且历史永久保留。
- 每日最多3次情报任务，手动启动间隔10分钟；每轮默认最多8次模型摘要（每来源均分），最多检查每来源12篇文章；文章失败可下轮重试。超20分钟终止。合同审查/追问/起草默认100次尝试/日，采集另计。
- 这些限制不是智谱账户消费硬上限，重建丢失数据目录也会重置计数。请在模型账户另设可接受的消费额度。

## 情报范围与已知限制

当前监测国家知识产权局政务栏目和最高人民法院知识产权法庭首页，法院源失败时尝试最高人民法院首页，并按知识产权关键词筛选。只覆盖栏目可见链接，不代表全部新增法规或裁判；网站改版或访问限制会使来源失败，状态明确展示。

正文只处理网页文本。若法规正文在PDF附件中，本版只整理公告页并明确显示“附件全文尚未解析”。首次采集可能含历史内容；依URL去重不追踪同URL修订，最近保留500条情报、5000条去重链接。不会把AI摘要直接作为已生效法律或自动发布成审查规则。智谱输出需要人工核验。

备份不包含密钥、合同或对话。恢复需管理员确认，会覆盖规则与情报，不恢复正在运行的任务和调度设置。情报恢复仅接受官方域名；恢复后共享规则版本递增。备份导入上限900KB，超大数据集需要按文件分批维护。
