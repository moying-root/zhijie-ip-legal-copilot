# 每日情报更新：部署与启用

此更新包不是已经上线的版本。没有智谱真实密钥，尚未验证真实模型摘要。默认只采集国家知识产权局首页、最高人民法院知识产权法庭首页可见文章，不覆盖全网；后者在本次网络测试返回404，需在实际任务中检查来源状态。首次收录可能是历史文章。抓取失败不编造数据。

## 上传代码

1. 解压更新包。在 GitHub 仓库首页上传其中 zhijie-tencent-deploy 文件夹，覆盖同名文件。不要上传 ZIP 本身。GitHub 的旧根目录 index.html 是原 Pages 演示版，本次更新针对腾讯云后端网站。
2. 仓库中新建文件 `.github/workflows/daily-intel.yml`，将包内“每日情报工作流.txt”的全部内容粘贴进去并提交。注意此文件在仓库根目录的 .github/workflows 下，不在 zhijie-tencent-deploy 下。
3. 仓库 Settings → Secrets and variables → Actions → Secrets，新建 ZHIPU_API_KEY，值为智谱 API 密钥。不能写到代码、工作流正文或截图。
4. 同页 Variables 新建 ZHIPU_MODEL，填写自己账户已开通模型名称，例如 glm-5.3。腾讯云已有变量不会自动共享给 GitHub。
5. Settings → Actions → General → Workflow permissions，允许 Read and write permissions。Actions 页选择“每日知识产权情报”，点击 Run workflow 首次运行。
6. 腾讯云开启 main 分支自动部署，目标目录仍为 zhijie-tencent-deploy；若机器人提交没有触发自动部署，需检查腾讯云 GitHub 触发器，或手动更新服务。保留 PUBLIC_ORIGIN 和智谱环境变量。
7. 任务将结果和采集状态提交到 zhijie-tencent-deploy/dist/intel.json；腾讯云新版本上线后页面读取 /api/intel。页面刷新按钮只读取已有结果，不触发收费的模型请求。

## 每日调度与费用

工作流计划北京时间每天08:00执行；GitHub调度可能延迟，公开仓库长期无活动可能暂停计划任务。每轮最多8次文章摘要调用，每来源最多4次，不足时不会填充虚构情报。失败文章可在下轮重试，已成功处理链接去重；仅保留最近500条情报与5000条去重链接，正文变更不会自动重新摘要。

智谱摘要消耗由账户支付。该独立任务不计入后端 DAILY_AI_LIMIT。没有每日新增时不生成新情报；采集状态和运行时间仍更新。摘要只是整理，不是已核实的生效法律，也不会自动写入审查规则。

公开仓库只保存官方链接、摘要及状态，不能放合同、客户资料或任何密钥。历史情报持久保存在 GitHub，后端容器无须写盘。删除已收录内容需要编辑 intel.json，同时处理 seen 链接。扩大来源、全文PDF、全网增量监测与人工审定流程尚待后续接入。
