# 腾讯云部署

将本包解压后的文件及 dist、server 文件夹上传到 GitHub 仓库根目录，不要只上传 ZIP。保留现有根目录 index.html 可继续使用 GitHub Pages。

服务名 zhijie；分支 main；服务端口 4173；目标目录留空；有 Dockerfile；名称 Dockerfile。

环境变量：
- PORT=4173
- HOST=0.0.0.0（Dockerfile 已配置）
- LLM_PROVIDER=zhipu
- ZHIPU_API_KEY=在腾讯云控制台填写真实密钥，不上传 GitHub
- ZHIPU_MODEL=账户已开通模型的准确名称，例如 glm-4.7
- DAILY_AI_LIMIT=100

创建服务后取得公网 HTTPS 访问域名，设置 PUBLIC_ORIGIN=https://实际域名（不带路径），保存并重新部署。配置前公网请求会返回 403，这是域名白名单保护；不能把示例域名作为真实地址。若平台健康检查可配置，使用 TCP 4173，或 HTTP /api/health 且 Host 为 localhost:4173。

API Key 设置是平台访问鉴权，不是智谱密钥；本方案前后端同源且面向公众，暂保持关闭。免费环境具体配额以控制台为准。

每天调用上限为单实例内存计数，重启会清零，不是账户消费硬限额。会话仅保存在内存。容器构建和腾讯云实机访问尚待部署验证。
