# 知界站内采集更新

## 使用

法律情报中心新增立即采集、进度、任务记录。公众可查看情报；手动采集需管理员口令，口令不保存在浏览器。任务为后台进程，浏览器关闭后可继续执行，但实例停止会中断。页面每5秒读取进度和情报；刷新情报只读取结果。

## 部署

解压更新包，在 GitHub 仓库首页上传 zhijie-tencent-deploy 文件夹覆盖同名文件，再等待腾讯云自动部署或手动更新服务。构建目标目录仍为 zhijie-tencent-deploy、Dockerfile 名称 Dockerfile、服务端口4173。保留现有 PUBLIC_ORIGIN、ZHIPU_API_KEY、ZHIPU_MODEL、LLM_PROVIDER。

新增环境变量：
- INTEL_ADMIN_TOKEN：使用密码管理器生成的随机长口令，建议至少24位（程序最低16位），仅在腾讯云填写，绝不写入 GitHub。用于知界“立即采集”弹窗，与智谱密钥不同。
- INTEL_AUTO_ENABLED：true 开启每日北京时间08:00任务，false关闭（默认关闭）。实例若在08点之后启动，当天尚无定时记录会在一分钟内补执行。至少一分钟检查一次。
- INTEL_MAX_ARTICLES：8，每轮最多8次模型摘要调用，失败尝试也计入本轮上限；可设1至30。
- INTEL_DATA_DIR：默认 /app/data；如有持久化存储请挂载可供容器node用户读写的目录，再设置此变量。

每实例每天最多3次采集；手动任务间隔至少10分钟；同一实例不能并发采集。计数和记录保存在数据目录。此功能仅适用于单实例，腾讯云最大实例数请设1，避免重复定时采集。每日采集额度独立于合同审查 DAILY_AI_LIMIT。

## 每日可靠运行和历史保存

容器必须保持运行，建议最小实例数1（可能增加费用，开通前核对腾讯云套餐）；缩容到0、平台停机时内置计时器不能唤醒容器。没有持续运行条件可保留GitHub外部调度方案，但应关闭站内 INTEL_AUTO_ENABLED，避免双重整理。当前版本没有接入托管数据库或跨实例锁；任务状态和情报仅写入本地数据目录，普通容器盘在重新部署/替换后可能丢失，不能当作持久化存储。

若改用站内自动采集，请停用 GitHub“每日知识产权情报”工作流，避免两个任务重复调用及独立数据源覆盖；不要同时部署旧包。初次启动会将 dist/intel.json 导入数据目录，已有数据目录则保留其内容。

## 核验

部署后进入法律情报中心，显示“管理员采集已配置”，点击立即采集填写管理员口令；可看到运行中、完成、部分失败、失败或中断，以及已整理篇数和模型调用数。接口返回202后无需等待整批文章完成。来源状态保留错误，不把模型接入或任务启动当作完整成功。

默认仅覆盖知识产权局和最高法知识产权法庭页面，法院来源此前网络测试404，需进一步适配；不承诺全部法律或案例覆盖。未在腾讯云实机验证此更新，真实智谱调用和自动运行需要部署后验证。AI摘要必须核对原文，来源链接由采集器提供而非模型生成。首次采集可能为历史内容。
